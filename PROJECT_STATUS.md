# CS 1.6 Valorant Android

## Target Engine
Xash3D FWGS Old Engine 0.19.2

## Target Device
Realme GT Master Edition
Snapdragon 778G
Android 13

## Features
- Offline CS 1.6 bots
- Valorant weapon skins
- Valorant kill banners
- Valorant kill sounds
- Kill streak tracking (up to 6 kills)
- Future LAN multiplayer

## Development
Cloud-based Android build using GitHub Actions.

Original Xash3D installation must remain untouched.
